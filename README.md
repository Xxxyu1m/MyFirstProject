# File Read Lab
This program reads student names and scores from a text file, and displays the letter grade.

## How to Run
1.Open the program in your IDE.
2.Enter student names and scores.
3.View the output.

## Example Input 
John 
Sarah 

## Example Output
Student grade:
John 85
Sarah 92
